# 每周 AI 产品文章 Agent

从真实素材出发，完成选题、草稿与公开信息检查，保留作者判断。

这是个人定制工作流的通用公开版，提供可复用方法和虚构示例，不含真实公司或客户资料。适合：持续写产品复盘、AI 实践文章的作者。

## 能解决什么

从真实素材出发，完成选题、草稿与公开信息检查，保留作者判断。 以输入材料与验证证据为依据，不把生成内容当成已完成的业务结果。

## 运行条件

支持 Markdown Skill 的 AI 客户端。近期热点需要联网能力；自动触发需要用户自己的调度器；云端同步需要连接器。

## 安装与调用

支持 Skills 的客户端：把整个仓库作为一个技能目录安装，目录名使用 `weekly-ai-pm-writer`。例如使用 Codex 时，复制到 `~/.codex/skills/weekly-ai-pm-writer`，然后重启客户端使其发现技能。已存在同名目录时先备份，不直接覆盖。

其他 AI 客户端也可以读取 `SKILL.md`，但本地脚本、文件写入、浏览及云端同步取决于客户端的工具与权限。

```text
用 $weekly-ai-pm-writer，根据本周素材给三个选题。只写有依据的内容，先生成本地草稿，不发布。
```

## 快速体验

先阅读 [虚构素材](examples/weekly-notes.md) 和 [练习短稿](examples/sample-draft.md)，再用自己的已获授权素材替换。不要将练习素材写成亲历。

手动使用时直接调用 Skill。需要定时运行时，将 [运行提示词](prompts/weekly-run.md) 配到自己的 AI 调度器；[配置示例](config/agent.example.json) 是说明格式，不能直接当作 Codex 自动化文件导入。默认 `enabled=false`、`auto_publish=false`，无任何实际云端目标。

推荐流程：素材 → 选题 → 作者选择 → 草稿 → [公开检查](references/privacy-checklist.md) → 作者确认 → 按明确指令同步。

## 文件入口

- `SKILL.md`：触发条件、流程与边界。
- `agents/openai.yaml`：技能显示信息与默认调用语句。
- `examples/`：虚构输入或输出示例。
- `VALIDATION.md`：本次实际执行的检查及未验证范围。
- `NOTICE.md`：来源、公开范围与许可说明。

## 使用限制

不包含独立模型服务或后台调度程序，不会自动发布文章。事实、语气及脱敏仍需作者复核。当前示例不构成一轮联网检索、运行成功或平台同步的证明。

## 资料与隐私

公开版本不依赖某家公司的客户表、内部文档标识、报价库或个人机器目录。真实使用时，输入、输出、截图及日志都需按资料权限管理；代码层的字段过滤无法识别自由文本里所有敏感信息。

本仓库不承诺生产环境效果。示例数字、名称和事件均为虚构，不可用作真实业务依据。当前许可状态见 [NOTICE.md](NOTICE.md)。
